# Buat Game Pertamamu — Petualangan GDevelop (SD 4–6)

Kursus satu halaman berbahasa Indonesia untuk anak SD kelas 4–6: membuat game **Endless Runner**
di GDevelop tanpa coding, mengikuti tutorial video Proxlight *"Make Your FIRST GAME In GDevelop"*.

- **Berjalan 100% dari repo ini** — gambar + klip video lokal (mp4, tanpa streaming/YouTube),
  jadi aman dibuka siswa di sekolah tanpa internet lancar.
- Klik tombol **▶** pada gambar untuk memutar potongan video asli (tanpa suara).
- Lihat `course/index.html` untuk mulai.
